# Avanzo Test Simulator 
Avanzo Test Simulator es una aplicación móvil educativa diseñada para facilitar y potenciar la preparación académica de estudiantes de bachillerato. Su principal objetivo es proporcionar una herramienta accesible y efectiva que ayude a los usuarios a reforzar sus conocimientos, practicar cuestionarios personalizados y medir su progreso académico de manera interactiva.

## Tecnologías Utilizadas
Kotlin: Lenguaje de programación para el desarrollo de la interfaz móvil.<br> 
Spring Boot: Framework para la creación de la API que conecta la aplicación con la base de datos.<br> 
PostgreSQL: Base de datos relacional utilizada para almacenar y gestionar la información del sistema.<br> 
Railway: Plataforma empleada para el despliegue de la API. 

## Instalación 
Por cuestiones de licencias y tiempos de respuesta de la Google Play Store, la aplicación aún no ha sido publicada en la tienda. Actualmente, los usuarios interesados deben instalar la aplicación manualmente desde el Android Studio.
